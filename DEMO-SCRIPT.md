# Demo Script: run of show

**Formats:**
- **Narrated:** `video/db2-backup-traceability-demo-narrated.mp4`, about 4 min 1 s, 1920x1080, voice only. Subtitles: `video/captions-narrated.srt`.
- **Silent:** `video/db2-backup-traceability-demo.webm`, about 2 min, no audio, with on-screen captions (`video/captions.srt`).

The last three scenes (architecture, what is deployed, conclusion) read from `ARQUITECTURE_2.md`.

**Audience:** bank audit and compliance leads, DBAs, mainframe application owners.

All figures are synthetic and illustrative. Product screens (IBM watsonx Assistant for Z, IBM ADDI for IBM Z) are simulated.

## Setup

```bash
npm ci
npm run build
npm run preview        # open http://localhost:4173 at 1920x1080
```

Or play either video in any player.

## Run of show (order of the video)

| Step | What happens on screen |
|---|---|
| 1. Dashboard | 4 KPI cards (222 image copies tracked) and the stacked bars: blue (Db2 catalog), teal (ADDI lineage), red (gap) |
| 2. Problem | Pain list and the "Days / Developers / Ad hoc / Failed" cards |
| 3. Solution, ask | General ledger scenario preselected, press Run trace |
| 4. Solution, Assistant and ADDI | Chat messages, checks appearing with timestamps, clock running |
| 5. Evidence | Green "Validated" tag, evidence ID, 7 checks |
| 6. Honest gap | Select Payment history, Run trace: red "Gap documented", skipped checks |
| 7. Results | Before and after cards and chart (illustrative targets) |
| 8. Architecture | IBM watsonx Assistant for Z diagram (simulated) |
| 9. What is deployed today | Status table: Built, Simulated, Not connected, Out of scope |
| 10. Conclusion | Conclusion and next steps diagram |

## Fallback

- Live app fails: play the narrated or silent video.
- Video will not play: open `screenshots/` in order (generated by `npm run video`).
- No network: everything runs locally with `npm run preview`.

## Reset

Reload the page. State is not persisted. On the Solution page, press Reset, or select another scenario.
