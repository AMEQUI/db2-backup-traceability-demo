# Synthetic data

`backups.json` is **synthetic**. It was generated by `scripts/generate-data.mjs` with a fixed seed (42) and a fixed "as of" date (2026-11-19), so it is identical on every run.

- Fictional bank "Meridian Financial"; fictional high-level qualifier `MRDN`.
- 37 month-end full image copies (Oct 2023 to Oct 2026) for 6 objects = 222 records.
- Dataset names, volume serials, job names and sizes are invented.
- Two records are deliberately marked `gap` (job ran, dataset not found) so the demo can show an honest "cannot prove" outcome.
- The 365-day catalog retention is illustrative.

Regenerate with `npm run data`.
